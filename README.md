# PDF Stamp — Пакетное наложение подписей и печатей на PDF

Утилита для автоматического размещения подписей и печатей на всех PDF-файлах в папке.
Настройки позиций задаются один раз через визуальный редактор и применяются ко всем документам.

---

## Что внутри

| Файл / Папка | Назначение |
|---|---|
| `setup_by_text.py` | Визуальный редактор позиций (GUI) |
| `batch_stamp.py` | Пакетное наложение подписей/печатей |
| `config.json` | Файл настроек (генерируется редактором) |
| `source/` | Папка для входных PDF-файлов |
| `done/` | Папка с результатами (файлы с суффиксом `-mod`) |
| `signature_*.png` | Файлы изображений подписей |
| `seal_*.png` | Файлы изображений печатей |
| `setup.bat` | Запуск визуального редактора (Windows) |
| `run.bat` | Пакетная обработка PDF (Windows) |

---

## Требования

- **Python 3.10+** (с галочкой `Add python.exe to PATH` при установке)\
  скачать Python можно по ссылке https://www.python.org/downloads/windows/ 
- ОС: Windows (батники), Linux/macOS (запуск через `python`)
- Подключение к интернету (первая установка скачивает зависимости)

## Быстрый старт

### Шаг 1 — Подготовьте PDF

Положите один или несколько PDF-файлов в папку `source/`.
Если папки нет — создайте её.

### Шаг 2 — Подготовьте изображения

Поместите файлы подписей и печатей в корень проекта:
- `signature_1.png`, `signature_2.png`, ... — подписи
- `seal_1.png`, `seal_2.png`, ... — печати

Формат: PNG с прозрачным фоном.

### Шаг 3 — Настройте позиции

**Windows:**
```
setup.bat
```

**Linux / macOS:**
```
python setup_by_text.py
```

Откроется окно визуального редактора:

1. Введите количество подписей и печатей.
2. Выберите элемент из выпадающего списка.
3. **Кликните левой кнопкой мыши** по слову в тексте PDF, рядом с которым должна быть подпись/печать.
4. Перетащите изображение мышью на нужное место.
5. Отрегулируйте размер ползунком/полем «Ширина» (в пунктах, pt).
6. Нажмите **ПРИНЯТЬ**.
7. Повторите для всех элементов.
8. Нажмите **Сохранить и выйти** — настройки запишутся в `config.json`.

> **ПКМ (правая кнопка)** — произвольная точка, если нужно разместить элемент вне текста.
>
> **Пропустить элемент** — пропустить текущий элемент без размещения.

### Шаг 4 — Обработайте документы

**Windows:**
```
run.bat
```

**Linux / macOS:**
```
python batch_stamp.py
```

Скрипт:
- Считает правила из `config.json`;
- Пройдет по всем PDF в `source/`;
- Наложит подписи и печати согласно настройкам;
- Сохранит результаты в папку `done/` с суффиксом `-mod` (например, `document-mod.pdf`).

Исходные файлы в `source/` **не изменяются**.

## Структура config.json

```json
{
  "background_threshold": 235,
  "rules": [
    {
      "image": "signature_1.png",
      "width": 80,
      "x": 350.5,
      "y": 120.3,
      "anchor_text": "Петров",
      "anchor_occurrence": 0,
      "offset_x": 15.0,
      "offset_y": 5.0,
      "page": 0
    }
  ]
}
```

| Поле | Описание |
|---|---|
| `background_threshold` | Порог удаления фона с изображений печатей (0–255). Чем выше — тем больше светлого фона удаляется. |
| `rules` | Массив правил наложения. |
| `rules[].image` | Имя файла изображения (подписи/печати). |
| `rules[].width` | Ширина элемента в пунктах (pt). Высота масштабируется пропорционально. |
| `rules[].x`, `rules[].y` | Абсолютные PDF-координаты (резервный режим). |
| `rules[].anchor_text` | Текст слова-якоря. Скрипт найдёт его на каждой странице и наложит элемент рядом. |
| `rules[].anchor_occurrence` | Номер вхождения слова-якоря (0 — первое, 1 — второе и т.д.). |
| `rules[].offset_x`, `rules[].offset_y` | Смещение от левого верхнего угла слова-якоря (в пунктах). |
| `rules[].page` | Номер страницы (0-based). Если указан якорь — применяется ко всем страницам. |

### Как работает наложение

1. Скрипт ищет `anchor_text` на каждой странице PDF.
2. При нахождении элемента с номером `anchor_occurrence` вычисляет позицию:
   `x = word.x0 + offset_x`, `y = word.y0 + offset_y`.
3. Помещает изображение размером `width` × (пропорциональная высота) в вычисленную точку.

Если якорь не найден — элемент пропускается с предупреждением.

## Устранение проблем

| Проблема | Решение |
|---|---|
| `Python не найден` | Установите Python с https://www.python.org/downloads/ и отметьте `Add python.exe to PATH`. |
| `config.json не найден` | Запустите `setup.bat` (или `python setup_by_text.py`) и сохраните настройки. |
| `В source/ нет PDF` | Положите файлы в папку `source/`. |
| `Изображение не найдено` | Проверьте, что файлы `signature_*.png` / `seal_*.png` лежат в корне проекта. |
| `Не удалось установить pdf-sign-kit` | Проверьте интернет-соединение; попробуйте установить вручную: `pip install pdf-sign-kit`. |
| Якорь не находится в документе | Убедитесь, что текст в `config.json` точно совпадает с текстом в PDF (без лишних пробелов). |
